# Pharmacy Expiry & Re-order Dispatch Engine

## Lab
Lab 1 – Requirements Engineering & UML Use-Case Modelling

## Problem Statement

A pharmacy requires an automated stock management engine that tracks medicine batch expiry dates, generates First-Expired-First-Out (FEFO) dispensing lists, and triggers automated purchase orders when inventory levels fall below configured reorder thresholds.

## Actors

- Pharmacy Clerk
- Inventory Manager
- Inventory Supplier

## Deliverables

- Requirements Table
- UML Use-Case Diagram
- Use-Case Specification

## Key Concept

The system follows the FEFO (First-Expired-First-Out) principle, prioritizing valid medicine batches with the nearest expiry date.
