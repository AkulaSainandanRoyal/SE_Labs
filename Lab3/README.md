## Project Overview

The proposed system helps pharmacy staff manage medicine batches and inventory, generate First-Expiry-First-Out (FEFO) dispensing lists, monitor reorder thresholds, and prepare purchase orders.

### Main Functional Areas

1. Medicine batch management
2. Inventory and expiry-status viewing
3. FEFO selection that excludes expired and zero-stock batches
4. Reorder-threshold monitoring
5. Purchase-order creation and dispatch-status recording
